HEAD BREAK / MARBLE LABYRINTH
ЗАДАНИЕ ДЛЯ CLAUDE: УСТАНОВИТЬ GODOT И ПОДКЛЮЧИТЬ ПРОЕКТ

Репозиторий: https://github.com/kirilsjanssen/marble-labyrinth
Цель: подготовить мой компьютер к совместной работе над существующей игрой Head Break.

1. Определи мою операционную систему и архитектуру компьютера.
2. Проверь, установлены ли Git и Godot. Если нет, помоги скачать и установить их из официальных источников:
   - Git: https://git-scm.com/downloads
   - Godot: https://godotengine.org/download/
3. В README проекта сейчас указана Godot 4.7.2 stable. Проверь совместимость и используй версию, необходимую актуальной ветке проекта; не обновляй проект автоматически до другой версии.
4. Проверь доступ к существующему репозиторию. Клонируй его на мой компьютер, начиная с ветки main. Новый репозиторий не создавай.
5. Если для клонирования или дальнейшего редактирования требуется доступ GitHub, помоги с безопасной авторизацией. Не проси пересылать пароли или токены в чат. Права на запись проверь отдельно, если понадобятся.
6. Если проект использует Git LFS, проверь наличие Git LFS и загрузку необходимых ресурсов. Не заменяй отсутствующие модели заглушками.
7. Найди файл project.godot, открой проект в редакторе Godot, дождись завершения импорта GLB, текстур и других ресурсов.
8. Запусти проект локально и проверь, что открываются меню и Level 05 — Alpine Cascade. Если другие уровни доступны, проверь их присутствие, но не меняй код.
9. Сообщи: ОС, версию Godot, путь к клонированному проекту, ветку/коммит Git, результат запуска, отсутствующие ресурсы и ошибки.
10. Если ты не можешь самостоятельно устанавливать программы или управлять моим компьютером, давай пошаговые команды и проверяй результат вместе со мной.

ОГРАНИЧЕНИЯ
- Ничего не изменять в исходниках и игровом проекте.
- Не выполнять commit, push или merge.
- Не создавать другой репозиторий и не перезаписывать main.
- Не устанавливать Blender и Unreal Engine.
- Не запускать Android Emulator.
- Не скачивать платные ресурсы и не использовать API-ключи.

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ
Godot и Git готовы к работе; существующий проект Head Break клонирован из GitHub, открывается в Godot и запускается локально. При проблемах — точный отчёт и инструкции по устранению, без самовольных изменений игры.
