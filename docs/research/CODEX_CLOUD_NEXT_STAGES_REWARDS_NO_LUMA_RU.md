## P6: СИСТЕМА НАГРАД, ЦЕЛЕЙ И ПРОХОЖДЕНИЯ — ОБЯЗАТЕЛЬНЫЙ РЕЗУЛЬТАТ

### 1. Data-driven Level Definition

У каждого уровня уникальный стабильный ID, название, краткое описание, обязательная цель (какой шар доезжает до финиша и/или какие условия), до 3 звёзд с настраиваемыми условиями, конфигурация пар-времени, checkpoints, уникальные collectibles и доступность уровня. Для разных уровней разные дополнительные условия: no_death, under_time, collect_coins_count, collect_all_crystals, activate_secret_switch, use_two_balls, finish_with_ball_type, both_balls_survive. Условия AND/OR и ясные зависимости, без жёстких if level==X в main.gd.

### 2. Как начислять 1–3 звезды

**1-я звезда**: обязательная цель уровня выполнена. Допускаются смерти, повторы после контрольной точки и долгое прохождение. Без финиша звёзд за данную попытку нет.

**2-я звезда**: заданный автором уровень мастерства — к примеру, 0 смертей *ИЛИ* завершение быстрее 90 с. Для конкретного уровня условие однозначно задаётся в данных. Если игрок умирает, можно продолжить и получить 1-ю звезду.

**3-я звезда**: особый челлендж конкретного уровня: собрать все кристаллы, найти скрытый маршрут, активировать секретный механизм, провести два шара, пройти за продвинутый лимит времени и т.п. Для уровня можно настроить составное условие, например 5 монет + тайный рычаг.

Звёзды считаются **по конкретному завершённому прохождению**: нельзя склеивать не связанные между собой частичные действия из разных попыток и объявлять их одной идеальной попыткой. Между прохождениями хранится максимум уже полученных звёзд; лучшее время хранится отдельно и не обязано происходить в той же попытке, что 3 звезды. Итоговое окно объясняет, какие условия выполнены и нет.

Ограничение 0..3, отсутствие двойной выдачи одной звезды, детерминированность при разном FPS.

### 3. RunStats и таймер

Данные текущей попытки: run ID, level ID, elapsed active time, deaths, respawns, checkpoint restores, manual full restarts, уникальные collected IDs, coins, crystals, puzzle triggers, unlocked balls, optional objectives, hints used, completion timestamp/flag, winner ball ID. Пауза/меню не увеличивает игровые секунды (документировать правило), время измерять по игровому tick. Возврат из чекпоинта **не сбрасывает deaths, time и collected IDs** текущей попытки; полный Restart Level начинает новую попытку, это должно быть видно игроку. Нельзя «обнулить» no_death простой загрузкой чекпоинта.

Урон/смерть как следствие физики: падение за карту, огонь/лава, шипы/вращающиеся механизмы — общий интерфейс сигналов Health/Damage/Checkpoint. Для текущих L01/L02 допускаются адаптеры, чтобы не сломать основной код.

### 4. Collectibles

**Монеты**: регулярные коллекционные предметы на необязательных маршрутах.
**Кристаллы**: более редкие/секретные элементы, часто привязаны к сложному пазлу.
Оба имеют уникальный collectible_id + level_id, физический Area3D-подбор от шарика, звук/анимацию-заглушку и HUD-счётчик; нельзя собирать повторно после респауна в рамках одной попытки. Позиция должна быть реально достижима с физикой шара и настоящими мостами/рампами.

Сохранение между попытками: хранить максимальный процент собранных предметов и список уникальных найденных редких кристаллов для коллекционного экрана. **Не превращать replay в бесконечную добычу глобальной валюты**: если появится общий счёт монет, начислять одноразово по unique collectible ID либо явно проектировать экономику без дублирования. Пока магазин/платёжка не нужны.

### 6. Два контрольных уровня

**Magnetic Relay:**
- алюминиевый шар открывает стальной;
- игрок переключается на стальной;
- магнит поднимает стальной к верхнему датчику;
- верхний датчик открывает ворота;
- игрок возвращается к алюминиевому и достигает финиша.
- звезда 1: алюминиевый финишировал;
- звезда 2: ни один шар не погиб;
- звезда 3: 5 монет И секретный верхний рычаг активирован.

**Cooling Crucible:**
- деревянный шар должен перейти горячий канал;
- удалённая кнопка может перекрыть подачу лавы;
- альтернативно вода временно охлаждает лаву до настоящей проходимой корки;
- нагрев снова разрушает корку, обжигает дерево; проверяемая смерть/respawn;
- звезда 1: деревянный финишировал;
- звезда 2: пройти без гибели;
- звезда 3: собрать 3 кристалла около водяных механизмов.

Общие учебные L01/L02 можно временно снабдить более простыми целями, чтобы система прогресса была проверяема до готовности сложных P4/P5.

## ТЕСТЫ — НЕ ОБОЙТИ

- Одно успешное прохождение -> 1 звезда; без смертей/цель -> 2; коллекционный челлендж -> 3. Все неуспешные условия корректно показаны.
- При смерти/respawn нельзя «сбросить» счёт смертей, отмотать накопленное время или повторно собрать монету.
- Повтор уровня после записи прогресса позволяет улучшить результат, но не размножает валюту и не понижает ранее заработанный лучший результат.
- Re-launch игры читает локальный прогресс из user://, persist best time, stars, IDs.
- При повреждённом save файле игра не падает; backup/defaults восстанавливают управление.
- Таймер не растёт на паузе, не зависит от FPS, 0..3 stars bounded.
- Два шара не исчезают при смене управления, камера/ввод переводятся; активаторы нажатые неактивным шаром остаются активны.
- Все текущие smoke Level 1/Level 2, P1 Physics Lab и mobile controls regression проходят.
- Godot 4.6.3 headless CI; Android APK GitHub Actions с автоматическим увеличением versionCode, тот же package com.kirilsjanssen.marblelabyrinth; только стабильная подпись владельца позволяет обновления поверх старой установки. Не использовать Android Emulator на слабом HP.
- Реальные акселерометр/мультитач/FPS/визуальный UX подтверждать только на физическом устройстве.
